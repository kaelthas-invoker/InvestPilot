# InvestPilot v0.2.1 SPEC — 柴犬 Logo 与加载动画

> 状态：设计已对齐（用户已确认像素造型）  
> 日期：2026-07-21  
> 依赖：v0.2 TUI 多轮聊天已完成

## 1. 目标

为 TUI 增加品牌感与加载反馈：

- 一只柴犬主题 Logo，像素块（block）风格，青蓝色系，可爱风
- **大 Logo**（狗头正面）：启动时在对话区首条展示
- **小 Logo**（侧面全身）：调用 LLM 期间在输入框上方从左向右跑动循环
- 不破坏 v0.2 的聊天、流式、错误恢复行为

## 2. 范围

### 2.1 In scope

| 项 | 说明 |
|----|------|
| Logo 资产 | `interface/logo.py`：狗头 ASCII、跑狗 3 帧、染色函数 |
| 大 Logo | `on_mount` 写入 transcript 第一条 |
| 跑狗动画 | 输入框上方状态行，生成中从左向右循环 |
| 配色 | 主色 `#35C4E8`；脸颊浅蓝、眼鼻深蓝 |
| 测试 | 资产行宽/帧数/偏移函数单测 |

### 2.2 Out of scope

- PNG/图片 Logo、README 图片
- 更多动画场景（报错狗、成功狗）
- 可配置关闭 Logo/动画（后续按需）

## 3. 视觉锚点与造型

真实柴犬参考特征：三角立耳、白色脸颊口罩、微笑嘴、卷尾（侧面）。

已确认造型（像素块，渲染预览已获用户采纳）：

### 3.1 大狗头（24 列 × 13 行）

要点：尖三角耳、深色方眼、浅青蓝脸颊口罩、微笑下颌、收底。  
逐行精确定义见 `PLAN.md` / `logo.py` 常量。

### 3.2 小跑狗（16 列 × 5 行，3 帧）

要点：头在左（耳、眼、吻）、右侧卷尾环、四腿三帧交替。  
第 1 帧四腿全立；第 2/3 帧前后腿交错，形成奔跑感。

## 4. 集成设计

### 4.1 大 Logo（on_mount）

- `InvestPilotApp.on_mount`：在欢迎语之前 mount 一个 `Static`（markup=True），内容为染色后的狗头多行字符串
- 随对话自然向上滚动；不占固定高度

### 4.2 跑狗动画（加载状态行）

- 输入框上方新增 `Static(id="thinking")`，默认 `display: none`
- `_handle_send` 开始：显示状态行，启动 `set_interval(0.15, tick)`
- `tick`：轮换 3 帧；横向偏移量 `offset = (offset + 1) % max_offset`，左 padding 递增实现"从左向右"，到右端回绕
- 收到首个 text chunk / done / error / 异常：停止 interval，隐藏状态行
- 流式回复文本仍写入对话区，与状态行互不影响

### 4.3 颜色

- 主色 `#35C4E8`（青蓝）
- 脸颊：浅青蓝 `#A9E5F5`
- 眼/鼻：深蓝 `#0C3C5A`
- 用 Rich markup（`[#35C4E8]█[/]`）或 Textual style；实现选一种并统一

## 5. 资产与接口

`interface/logo.py` 暴露：

```text
HEAD_ART: list[str]      # 13 行，每行 24 列（含 █ ▄ ▀ ░ 占位）
RUN_FRAMES: list[list[str]]  # 3 帧，每帧 5 行，每行 16 列
run_frame_text(index: int, offset: int) -> str
render_head_markup() -> str   # 染色后可直接给 Static
```

- `░` 在狗头中表示脸颊浅蓝
- 眼睛用深色标记（实现细节在 PLAN 中固定）

## 6. 错误处理

- 动画 tick 内任何异常 → 静默停止并隐藏状态行，不影响聊天
- 无 TTY / 极简终端：动画退化为静态"思考中…"（若实现成本低于检测，可不做，保持现状）

## 7. 验收标准

1. `invest-pilot chat` 启动后，对话区首条可见青蓝像素狗头
2. 发送消息后、收到首个 token 前，输入框上方出现从左向右跑动的小狗
3. 回复流式开始后动画停止并消失；再次发送会复现
4. 报错时动画同样停止，错误行正常显示
5. 连续多轮对话功能不受影响
6. `pytest`、`ruff` 通过；logo 资产有单测

## 8. 测试计划

| 测试 | 要点 |
|------|------|
| logo 资产 | HEAD_ART 行数=13、每行宽度=24；RUN_FRAMES=3 帧、每帧 5 行、宽度=16 |
| run_frame_text | offset 增加时内容变化，且长度恒定 |
| TUI 回归 | 现有 helper 测试仍通过 |
| 全量 | `uv run pytest`、`uv run ruff check .` |

## 9. 风险

| 风险 | 缓解 |
|------|------|
| Textual 动画与 worker 竞争 | tick 只做轻量字符串替换；异常即停 |
| 终端宽度 < 24 列狗头被截 | 最小可接受宽度文档化；不缩放（v0.2.1） |
| 配色在某些终端偏色 | 使用标准 24-bit；不依赖主题变量 |
